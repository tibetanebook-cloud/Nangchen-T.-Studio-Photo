Tibetan Design Photo portable mode

While this file sits next to photocraft.exe, Tibetan Design Photo keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the Tibetan Design PhotoData folder beside it, and writes
nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Tibetan Design Photo with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\Photocraft for settings
and %LOCALAPPDATA%\Photocraft\Recovery for crash-recovery autosaves. If Tibetan Design PhotoData can't be
written (for example on a read-only drive), Tibetan Design Photo says so and uses those folders instead.
