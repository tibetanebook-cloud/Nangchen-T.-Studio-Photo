Tibetan Design portable mode

While this file sits next to photocraft.exe, Tibetan Design keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the Tibetan DesignData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move Tibetan Design with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Photocraft) instead.
If Tibetan DesignData can't be written (for example on a read-only drive), Tibetan Design says so and
uses %APPDATA%\Photocraft instead.
